# JT Barber — website

Site one-page pour **JT Barber** (barbeiro • Maringá, PR • Brasil).

- 🌍 4 langues : **Português (par défaut)**, English, Français, Kreyòl ayisyen — détection automatique selon la langue du téléphone, avec sélecteur manuel.
- ✂️ Services, galerie, à propos, étapes, FAQ.
- 📅 Formulaire de **demande de disponibilité** → envoie le message pré-rempli sur WhatsApp ou par e-mail.
- ✂️ Catalogue de 13 modèles de coupe (Fade, Taper, Burst, Waves, Twists, Afro, Buzz, Crop, Freestyle, Barbe…) avec filtres + bouton « Je veux cette coupe » qui pré-remplit le formulaire.
- 🎬 Motion design (GSAP + ScrollTrigger + Lenis) : preloader compteur, titres lettre par lettre, image qui s'agrandit au scroll, services en scroll horizontal, ciseaux qui coupent la ligne, marquees réactifs, texte qui s'allume mot par mot, curseur custom, boutons magnétiques.
- 📞 Contacts uniquement sous forme de boutons (WhatsApp, Appel, E-mail, TikTok, Instagram).

Pour mettre tes propres photos : ajoute-les dans `assets/looks/` et change le champ `img` dans `styles-data.js`.
- 100 % statique (HTML/CSS/JS) — déployable sur GitHub Pages, Netlify ou Vercel.

## Lancer en local
Ouvrir `index.html`, ou : `python3 -m http.server 8000`
